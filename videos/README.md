# Hero video

`index.html` plays `videos/hero.mp4` in the hero blob (autoplay, muted, loop, playsinline),
with `images/hero.jpg` as the poster and fallback image.

Drop the final video here as **`hero.mp4`** (H.264, 4:3 to match the poster, ideally under 5 MB).
Until the file exists, the page shows the poster image.
